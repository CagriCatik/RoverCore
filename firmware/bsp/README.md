# Firmware bsp

Board-specific code; the only place that touches GPIO / ADC registers.

- `esp32s3/rovercore_pins.h`: generated by `../tools/gen_pins.py` from
  `hardware/interfaces/pinmap.csv`. Do not edit; `gen_pins.py --check` runs in the host tests.
- `esp32s3/board_io.c/.h` (ESP-IDF v5.x): safe start-up levels (SERVO_PWR_EN low,
  ACT_OE_N high), inputs without internal pulls (bench option for a bare DevKit only),
  ACT_ARMED_FB falling-edge interrupt, ADC1 oneshot with curve-fitting calibration.

See `docs/vcu/firmware-plan.md`.
